# OpenLaunch Radar

OpenLaunch token monitoring dashboard for Base, Robinhood Chain, and Arc.

OpenLaunch Radar is an on-chain market intelligence terminal that monitors token activity, trading flow, volume movement, and market signals using OpenLaunch public data sources.

## Requirements

- Windows 10/11
- Node.js LTS
- Visual Studio Code

## Run Locally

npm install
npm run dev

## Features

- Multi-chain token monitoring
- Search and filtering
- Watchlist
- Volume monitoring
- Activity alerts
- Trend Score activity indicator

## Disclaimer

OpenLaunch Radar provides market activity analysis only. It is not financial advice or a recommendation to buy any token.
